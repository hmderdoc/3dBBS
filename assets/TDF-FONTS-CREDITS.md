# TheDraw font credits

The pre-login splash renders the product name in TheDraw
(`.tdf`) fonts drawn by ANSI-scene artists, mostly in the
1990s. Only the finished renderings of one string are
compiled in (see `assets/gen_tdf_splash.py`); no font file
is redistributed.

Fonts come from the collection shipped with Synchronet
(`ctrl/tdfonts/` in SynchronetBBS/sbbs), which is where
the artwork has been redistributed for decades. Font names
are as recorded in each file's header; where a name carries
an artist or group tag it is preserved verbatim.

If you are an author here and want a font removed, open an
issue and it will be dropped from the next release.
